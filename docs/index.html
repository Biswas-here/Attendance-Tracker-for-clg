✨ Features

🏠

Live Class Card

See your current class front and centre — teacher, room, and timings at one glance.

✅

One-Tap Marking

Mark Present or Absent instantly. Swipe to switch. No extra taps.

🔔

Smart Notifications

Advance class reminders and unmarked-attendance alerts — even when the app is closed.

📊

Powerful Analytics

Subject-wise attendance bar chart, predictive advice, and colour-coded attendance ring.

📄

CSV Import

Import your full timetable from a spreadsheet in seconds — teacher and room auto-filled.

🌙

Light & Dark Mode

System-aware theming with zero flash on startup. Looks great in both modes.

📴

Fully Offline

Local SQLite database. No account, no cloud, no internet required.

🎓

Semester Tracker

Set semester start/end dates. Get a personalised congratulations at the end.

🛠️ Built With

Flutter 3.x Dart 3.x SQLite (sqflite) Provider fl_chart flutter_local_notifications file_picker path_provider shared_preferences
