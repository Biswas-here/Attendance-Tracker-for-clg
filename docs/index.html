💡 The Idea Behind The App

Why we built Attendance Ledger and how it solves real daily college challenges.

The College Reality

Most universities enforce a strict 75% or 80% mandatory attendance threshold. Falling below this cut-off means detention, exam hall ticket disqualification, or academic penalties.

Yet keeping track manually is a nightmare:

  • Calculating percentages manually after every bunked class is tedious and error-prone.
  • Lab sessions count for multiple hours, throwing off simple tally marks.
  • Existing store apps are loaded with ads, require cloud logins, or fail completely when offline.
  • Forgetting to mark attendance because notifications don't fire when the app is closed.

The Smart Solution

Attendance Ledger was created as a distraction-free, 100% private, offline-first companion tailored specifically for college students.

It acts as your personal attendance assistant:

  • Predictive Intelligence: Tells you exactly how many consecutive classes you can safely skip or must attend to hit your target.
  • Live Class In Session: Prominently highlights your current class with teacher name, room, and timings.
  • Smart Lockscreen Actions: Mark Present or Absent directly from Android notification buttons without even opening the app.
  • Bulk CSV Import: Import your entire college timetable in 5 seconds without entering classes one by one.

🛠️ Languages & Tech Stack

The modern languages, frameworks, and low-level system APIs powering Attendance Ledger.

🎯

Dart

Core Programming Language

Type-safe Dart 3 powers all application models, business calculations, attendance algorithms, and asynchronous streams with zero runtime null-errors.

📱

Flutter

UI & Animation Engine

Google's cross-platform framework rendering a paper-crafted aesthetic with 60 FPS smooth animations, responsive grids, and zero-flicker light/dark themes.

💾

SQLite & SQL

Local Database Engine

High-performance embedded SQLite database (`sqflite`). Executes indexed local queries on-device with zero reliance on cloud or internet servers.

🤖

Kotlin & Java

Android Native Layer

Native Android integration for Android AlarmManager, BroadcastReceivers, NotificationChannels (API 21-34+), and background lockscreen actions.

⚙️

C++ & CMake

Engine Embedding

Native Flutter engine embedding and build pipeline automation linking low-level platform channels and graphics compilation.

🌐

HTML5 & CSS3

Web & Documentation

Clean semantic markup and modern CSS variables powering this responsive GitHub Pages showcase and user documentation.

✨ Core Features

Built from the ground up to give you total control over your semester.

🔔

Reliable Background Notifications

Guaranteed alerts even when the app is completely closed: early reminder, class start alert with PRESENT / ABSENT action buttons, and automatic post-class unmarked notification.

📊

3D Analytics & Bunk Calculators

Visual 3D vertical pillar comparison chart with horizontal labels for long subject names. Tells you exactly: "You can safely miss 3 more classes" or "Attend 2 consecutive classes to reach 75%".

📅

One-Tap CSV Timetable Import

Import your entire weekly semester schedule from Excel or CSV. Automatically extracts subject titles, faculty names, room numbers, and schedules up to 52 weeks.

⚡

Smart Class In Session Card

Front-and-centre hero card displaying your ongoing lecture, room number, faculty name, and a 1-tap toggle to switch between Present and Absent.

🌓

Seamless Light & Dark Theme

Warm paper-toned light palette and deep OLED dark mode with zero startup flash. Settings pre-load before the first frame renders.

🛡️

100% Offline & Private

No account, no sign-in, no tracking, and no internet required. Your attendance and profile data remain completely secure on your personal phone.
